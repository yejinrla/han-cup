# 구현 상태와 결정 기록

로컬 MVP 구현: C안 반응형 도감, 검색·영양 필터·정렬, 실제 변형별 상세, 3개 비교, 카카오/Supabase 인증 연결 코드, 찜, 반복 음용 기록·공개/비공개·최신 공개 평점, 신고·운영 숨김, 계정 설정·탈퇴 연결, 카카오 매장 지도·목록·외부 연결, 검수 발행·복구 도구.

## 실행 중 결정

- 클라우드 스킬의 실행 보조 스크립트가 로컬 파일로 제공되지 않아 같은 작업 기록·검증 증거를 직접 기록했다. 비용: 자동 bookkeeping 대신 수동 추적.
- 기본 홈 디렉터리의 npm 캐시를 쓸 수 없어 /tmp의 작업 전용 캐시를 사용했다. 비용: 캐시는 임시이며 재설치 시 다시 다운로드한다.
- 매장 검색은 계획의 GET 대신 POST JSON body로 전달한다. 이유: 사용자의 정밀 위치가 URL 로그에 들어가지 않도록 한다. 비용: API 호출자는 POST를 사용해야 한다.
- 전체 Supabase 스택이 클라우드 디스크를 초과해 공식 GoTrue/PostgREST와 실제 PostgreSQL만으로 인증 통합 테스트를 실행했다. 비용: hosted gateway와 실제 Kakao 공급자 설정은 별도 출시 검증이 필요하다.
- 공식 원문과 대조한 로컬 공개 미리보기와 운영 DB 발행을 분리했다. 비용: 운영 DB는 사람이 승인한 검수 배치를 발행하기 전까지 비어 있다.
- 인증 테스트용 Next 출력은 .next-auth로 분리했다. 이유: 두 로컬 서버가 출력물을 공유하지 않게 한다. 비용: 추가 디스크 사용.
- 리뷰의 공유 비교 제거 문제는 비교 결과를 잃는 기능 결함으로 판단해 Important로 상향했다. URL의 남은 선택을 유지하고 그 결과를 로컬 저장소에 동기화했다. 비용: URL을 현재 비교 화면의 기준으로 삼는다.
- 새 변형을 추가한 발행의 롤백은 자동 복구하지 않고 명시적으로 거부한다. 이유: 기존 음용 기록의 참조를 보존하면서 잘못된 복구 성공을 보고하지 않기 위해서다. 비용: 운영자가 제품 판매 종료 또는 검수 후 정정 발행으로 처리해야 한다.

- 새 저장소에는 기존 기준 브랜치와 원격 저장소가 없어 feat/hancup-mvp를 로컬에 보존했다. 비용: 원격 통합은 사용자 소유 저장소를 정한 뒤 진행한다.

## 독립 리뷰 처리

Critical 없음. Important 4개와 상향한 기능 결함 1개를 회귀 테스트로 재현하고 수정했다.

- 공개 후기 본문은 서버 컴포넌트 이력 캐시에 넣지 않는다. 화면을 떠나기 전에 지우고, 복귀·포커스 복원 시 no-store API의 최신 공개 조회가 끝나기 전에는 표시하지 않는다. 서버 캐시 복구가 지연되는 상황을 두 세션 브라우저 테스트로 확인한다.
- 변형 UUID의 제품 소유권·온도·사이즈를 잠금 후 확인하고 전체 배치 ID 중복을 거부한다. UPSERT에도 동일 소유권 조건을 적용한다.
- 새 변형이 남는 롤백은 성공 처리하지 않는다. 전체 트랜잭션을 되돌리고 release.reverted=false를 유지한다.
- 중복 ids URL 매개변수는 합쳐서 중복 제거하고 최대 3개로 제한한다. 로그인 next 매개변수도 문자열 외 값은 안전한 기본 경로를 사용한다.
- 공유 비교에서 하나를 제거하면 URL에 있던 나머지 선택이 유지된다.

## 후속 개선으로 남긴 Minor

- 지도 SDK가 응답 없이 지연되거나 글로벌 객체 없이 load되는 경우의 초기화 타임아웃·재시도. 매장 목록과 외부 지도 연결은 이용 가능하다.
- 지도 마커와 매장 목록의 선택·중앙 이동 연동. 현재는 지도 핀과 목록을 함께 제공한다.

## 리뷰에서 별도 판단한 범위

- 실제 hosted 인증·지도·탈퇴·배포, 6개 브랜드 생산 데이터, 정식 개인정보 처리방침은 출시 게이트다. 로컬 테스트로 완료 처리하지 않는다. 잘못 넘기면 실제 서비스 연결이나 데이터 신뢰성이 깨지므로 release-checklist가 막는다.
- 리뷰어는 DB를 변경하는 전체 테스트를 재실행하지 않았다. 작성자가 로컬 실제 DB·브라우저 명령을 재실행해 증거를 기록한다. 비용: 독립 리뷰는 코드 검토이며 테스트 실행 주체는 작성자다.
- 이미 공개됐을 때 사용자가 따로 복사하거나 캡처한 내용까지 회수하지 않는다. 앱이 철회된 내용을 자체 캐시에서 다시 보여주는 문제는 수정한다. 비용: 이미 전달된 사본은 회수할 수 없다.
