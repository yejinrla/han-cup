# 주변 매장과 무료 사용

Kakao Maps JavaScript 키는 NEXT_PUBLIC_KAKAO_MAP_KEY, Local REST 키는 KAKAO_REST_KEY. 같은 앱에서 Map/Local 사용과 실제 도메인 허용을 확인한다. 개발자 계정의 무료 적용 가능 여부·앱 활성화 순서를 최신 대시보드에서 직접 확인한다. 무료가 적용되지 않으면 유료 사용을 활성화하지 않는다.

검색은 선택 브랜드, 카페 분류, 최대 10km 반경, 거리순 15개씩 최대 3페이지. 지역명은 주소 좌표로 변환한 뒤 검색한다. 잘못된 브랜드 이름의 결과는 거른다. 실시간 영업·판매·재고는 보장하지 않는다.

현재 위치는 버튼 클릭·권한 허용 때만 사용하며 POST JSON body로 전달한다. URL에 좌표를 넣거나 DB에 저장하지 않는다. 서버에는 카카오 결과를 영구 복제하지 않는다. SDK/REST 실패·권한 거부 시 카카오맵 검색 연결과 지역명 검색이 남는다.

KAKAO_DAILY_SEARCH_BUDGET은 실제 무료 사용량보다 충분히 낮게 정한다(코드의 1000은 앱 검색 요청 예산의 보수적 시작값이며 Kakao가 보장한 무료 쿼터가 아님). 지역 검색은 주소 조회와 장소 조회 두 API를 쓰므로 각 API의 무료 제한도 따로 확인한다. 전역 DB 예산과 클라이언트당 분당 15회를 적용한다. 호출 제한용 일별 해시만 저장하고 하루 지난 클라이언트 예산은 정리한다. 실제 정밀 위치나 IP 원문을 애플리케이션 로그에 남기지 않는다. 호스팅 로그 설정도 점검한다.

지도 SDK는 10초 안에 준비되지 않거나 스크립트 오류·전역 객체 부재 시 실패로 처리하고, 사용자가 누를 때만 다시 요청한다(자동 재시도 없음). 브라우저 테스트는 `NEXT_PUBLIC_KAKAO_MAP_KEY`에 비밀이 아닌 임시값을 쓰고 dapi.kakao.com 요청을 기본 차단하며, 필요한 테스트만 가짜 SDK로 응답한다.

무료 쿼터·검색 예산을 초과하면 429와 외부 카카오맵 연결을 제공하며 자동 유료 전환하지 않는다. SDK 지도 로드 자체의 사용량도 Kakao 대시보드에서 확인해야 한다.
