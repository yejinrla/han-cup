# 한컵 UI 문구 원칙

2026-11-16 사용자 승인: 서비스명은 ‘한컵’이며 메뉴·버튼·안내마다 ‘한 잔’을 반복하지 않는다. 모든 표현을 기계적으로 ‘한컵’으로 바꾸지도 않는다.

- 기능은 구체적으로: ‘음료 기록’, ‘음료 기록하기’, ‘음료 메모’, ‘주변 매장 찾기’.
- 상태 안내는 결과로: ‘기록을 저장했어요’, ‘페이지를 찾을 수 없어요’.
- 홈 제목: ‘오늘은 어떤 음료가 끌리나요?’
- 영양 기준 탭: ‘1회 제공량’ / ‘100ml 기준’. 문구만 바뀌며 계산 방식은 동일하다.
- 매거진 글 제목·본문 등 편집 콘텐츠에는 문맥에 자연스러운 ‘한 잔’을 허용한다.
- 사용자가 작성한 기록 본문이나 기존 저장 데이터는 수정하지 않는다.

검증 기록: lint·build·typecheck 및 단위/DB 76개, 실제 로컬 세션 8개 통과. 공개 브라우저 검사는 68개 통과, 모바일 검색 가독성 1개가 networkidle 대기 중 시간 초과했으며 해당 검사는 코드 변경 없이 단독 재실행에서 통과했다. 390px 홈 화면과 320px 영양 기준 탭 배치를 확인했다.
