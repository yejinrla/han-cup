# 배포와 출시 게이트

현재는 사용자 계정으로 외부 프로젝트를 생성하거나 공개 배포하지 않았다. Vercel Hobby는 개인·비상업 사용과 제공량 내 운영을 전제로 한다. 상업화 때 요금·약관을 재검토하고 무료 유효 기간과 공급량을 다시 확인한다.

1. 사용자 소유 Git 저장소에 연결하고 Vercel에서 Next.js 프로젝트를 설정한다. 유료 도메인 대신 제공되는 도메인을 사용한다.
2. Supabase/Kakao 설정과 서버 비밀 환경변수를 분리하고, 실제 도메인·콜백 허용 목록을 설정한다. 무료/비상업 적합성·자동 과금 미활성 상태를 확인한다.
3. 6개 브랜드 각각의 공식 데이터 확보와 사람 검수를 완료한다. 미리보기 초기 파일을 자동으로 운영 DB에 올리지 않는다. 가격 미제공과 제품 사진 대체가 서비스 목적에 맞는지 확인한다.
4. 개인정보 처리방침의 운영자·문의처·처리 위탁·보유 및 삭제 기간을 확정하고 정식 안내를 게시한다. 초안 상태에서는 공개 회원을 모집하지 않는다.
5. `release-checklist.md`의 로컬 검증과 실제 Kakao OAuth/Map/탈퇴 검증을 분리해서 기록한다. 검증용 계정의 실제 탈퇴는 삭제 전 당사자가 확인한다.
6. 사용자가 검토할 실행 화면과 증거를 제공한 뒤 공개 배포 승인을 받는다. 배포 후 실제 도메인에서 익명·로그인 사용 흐름을 확인한다.

Supabase가 비활성 상태로 중지되면 대시보드에서 복구 후 연결·접근 제어를 다시 점검한다. 무료 한도 도달 시 장애 안내·외부 지도 연결을 제공하며 임의 유료 전환을 하지 않는다.

공식 요금: https://supabase.com/pricing · https://vercel.com/docs/limits/fair-use-guidelines · https://developers.kakao.com/docs/ko/getting-started/quota
