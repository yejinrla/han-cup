# 아티클 좋아요 운영 연결

운영 적용 상태: 2026-11-14 사용자가 `008_article_favorites.sql`을 실행했고 확인 쿼리에서 `public.article_favorites` 테이블 존재를 확인했다. 로그인 후 하트 → 좋아요 아티클 탭 → 해제 흐름의 실제 운영 확인은 아직 기록되지 않았다(`docs/operations/production-db.md`).

기존 한컵 Supabase 프로젝트의 SQL Editor에서 `supabase/migrations/008_article_favorites.sql` 전체를 한 번 실행한다. 재실행 가능하며 기존 음료 좋아요·음료 기록을 변경하거나 삭제하지 않는다. 새 테이블의 읽기·추가·삭제는 본인 계정으로 제한하고, 사용자 탈퇴 시 함께 삭제된다.

코드 배포만 하고 SQL을 실행하지 않았다면 기존 음료 좋아요와 아티클 읽기는 유지되고, 아티클 좋아요는 준비 중으로 표시한다. SQL 실행 후 화면을 새로고침하고 로그인해서 아티클 상세 하트 → 좋아요의 아티클 탭 → 상세 재방문 → 해제를 확인한다. 로그인 전 하트를 누르면 로그인 후 해당 글을 저장할지 확인한다.

계정 키를 변경하거나 월렛을 연결할 필요는 없다. 이 기능에 운영 DB 자격 증명을 추가로 제공할 필요도 없다. 로컬 권한 테스트와 세션 테스트 결과를 운영 연결 완료로 간주하지 않는다.
