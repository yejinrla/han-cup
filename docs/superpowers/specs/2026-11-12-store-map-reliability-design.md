# 주변 매장 지도 안정성과 목록 연동

작성일: 2026-11-12 (한국 시간). 상태: 초안 — 사용자 승인 대기. MVP에서 후속 Minor로 남긴 두 항목(implementation-status.md)을 다룬다.

## 목적
카카오 지도가 늦거나 깨져도 사용자가 무한 대기하지 않고 다시 시도할 수 있게 한다. 지도 핀과 매장 목록을 서로 연결해 어느 핀이 어느 매장인지 바로 알 수 있게 한다. 매장 검색·목록·카카오맵 외부 연결은 지도 상태와 관계없이 계속 동작한다.

## 현재 문제
- SDK 스크립트가 로드됐지만 `window.kakao`가 없으면 로딩 약속이 끝나지 않는다.
- 응답 없는 SDK 요청에 시간 제한이 없다. 실패·지연된 로더가 모듈에 남아 새로 고침 전에는 재시도할 수 없다.
- 지도 핀과 목록이 연결되지 않는다. '매장 더 보기'마다 지도를 새로 만들어 사용자가 옮긴 위치·확대 수준이 초기화된다.

## 동작

### SDK 로딩
- 스크립트 로드와 `kakao.maps.load` 완료까지 하나의 제한 시간(기본 10초) 안에 끝나야 한다. 시간 초과, 스크립트 오류, 로드 후 `kakao.maps` 부재는 모두 실패로 처리한다.
- 실패하면 지도 영역에 "지도를 불러오지 못했어요. 아래 매장 목록을 이용해 주세요."와 **지도 다시 불러오기** 버튼을 표시한다. 재시도는 실패한 스크립트 요소와 캐시된 로더를 버리고 새로 요청한다. 자동 무한 재시도는 하지 않는다(무료 사용량 보호).
- 이미 성공한 SDK는 재사용한다. 화면을 떠난 뒤 늦게 도착한 성공·실패는 화면 상태를 바꾸지 않는다.
- 키 미설정·검색 전 안내 문구는 지금과 같다.

### 지도와 목록 연동
- 지도는 화면당 한 번 만들고, 검색 결과가 바뀌면 핀만 다시 그린다. 새 검색이면 첫 매장(거리순 가장 가까운 곳)으로 중심을 옮긴다. '매장 더 보기'로 추가된 경우에는 사용자가 보던 위치·확대 수준을 유지한다.
- 핀을 누르면 해당 매장이 목록에서 선택 상태가 되고, 목록에서 보이도록 스크롤한다.
- 각 매장 카드에 **지도에서 보기** 버튼을 둔다. 누르면 그 매장이 선택되고 지도가 해당 핀으로 이동한다. 핀은 키보드로 접근하기 어려우므로 이 버튼이 키보드·보조기기 사용자의 동등한 경로다. 버튼은 `aria-pressed`로 선택 상태를 알린다.
- 선택된 매장은 카드 테두리와 배경을 기존 초록 강조색으로 구분하고, 지도에서는 선택된 핀을 다른 핀과 구분한다(카카오 SDK의 기본 마커 이미지 교체 또는 z-index·크기 차이, 구현에서 SDK가 지원하는 방식 선택). 색만으로 구분하지 않도록 카드에 "선택됨" 텍스트 표시를 함께 둔다.
- 새 검색·브랜드 변경 시 선택은 해제된다. '매장 더 보기'에서는 유지된다.
- 지도 로딩에 실패한 상태에서도 '지도에서 보기'는 선택 표시만 바꾸고 오류를 내지 않는다.

## 유지하는 원칙
위치는 버튼 클릭 때만 요청하고 URL·DB에 저장하지 않는다. 카카오 결과를 서버에 복제하지 않는다. 실시간 영업·판매·재고를 표시하지 않는다. 기존 C안 초록·크림 스타일과 480px 앱 화면을 유지한다. API·DB 변경은 없다.

## 접근 대안
1. 핀 클릭 시 지도 위 정보창(InfoWindow) 표시: 지도 안에서 정보가 끝나지만 480px 화면에서 지도를 가리고, 목록과 정보가 중복된다.
2. 핀 클릭 시 목록 카드 선택·스크롤(선택): 이미 있는 목록 카드를 그대로 쓰고 키보드 경로와 같은 상태를 공유한다.

## 제외
클러스터링, 지도 이동 시 재검색, 길찾기 내장, 영업 중 표시, 자동 재시도는 범위 밖이다.

## 검증
- SDK 시간 초과, 스크립트 오류, 로드 후 전역 객체 부재 각각이 실패 안내와 재시도 버튼으로 끝나고, 재시도가 새 요청을 만든 뒤 성공할 수 있다.
- 화면 이탈 후 늦은 응답이 상태를 바꾸지 않는다.
- 핀 클릭 ↔ 목록 선택, '지도에서 보기' ↔ 지도 중심 이동, 새 검색 시 선택 해제, 더 보기 시 선택·지도 위치 유지.
- 실제 카카오 SDK 대신 테스트용 가짜 SDK를 쓰며, 실제 카카오 지도 확인은 기존 출시 게이트로 남긴다.
- 320/390/1440px에서 가로 넘침 없음, 키보드로 선택 가능.
