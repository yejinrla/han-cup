# 취향 노트 카드와 추천 글

사용자 승인: 홈 검색창 바로 아래에 추천 글 카드1개를 두고, 누르면 본문과 추천 음료가 있는 내부 상세 화면으로 이동한다. 첫 글은 '가을에 마시기 좋은 차 추천'. 기존 초록·크림색과 따뜻한 베이지 카드, 작은 차 일러스트를 사용한다.

추천은 에디터의 취향 제안이며 판매 순위·건강 효능·개인 맞춤 분석으로 표현하지 않는다. 글은 로컬 콘텐츠로 관리하고 현재 도감의 활성 제품/기본 변형에만 연결한다. 첫 글은 따뜻한 매실 모과차와 시원한 상큼 리치티 두 선택을 소개한다. 운영 DB에 아직 없는 추천 제품은 원문을 꾸며 채우지 않고 준비 중 안내를 표시한다. 상세 페이지는 /notes/autumn-tea이며 홈 탭을 유지하고 홈/전체 차 탐색 링크를 제공한다. 별도의 CMS나 DB 마이그레이션은 없다.
