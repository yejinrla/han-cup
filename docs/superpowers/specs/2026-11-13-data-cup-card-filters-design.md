# 데이터로 그리는 컵, 압축 카드, 한 줄 검색 필터 (UI 개선 2단계)

작성일: 2026-11-13 (한국 시간). 상태: 사용자 승인 완료(2026-11-13, "2단계 진행"). UI 개선안(https://claude.ai/artifact/AQs87mnHFYTzQtNqk53MHv)의 제안 1·2·3이다. 1단계(가독성·온도에 맞는 컵) 위에서 진행한다.

## 목적
제품 사진이 없는 동안 컵 그림이 검수된 정보를 전달하게 하고, 한 화면에 더 많은 음료가 보이게 하고, 검색 첫 화면을 차지하는 필터를 정리한다. 기능·데이터·URL 규칙은 바꾸지 않는다.

## 1. 데이터로 그리는 컵
- 컵 높이는 컵 용량에 비례한다. 710ml를 최대 높이로 두고 355ml는 절반 높이다. 710ml보다 크면 최대 높이로 그린다.
- 용량이 없는 변형은 591ml 높이에 점선 외곽으로 그리고, 대체 텍스트에 "용량 미제공"이라고 쓴다.
- 모양은 온도다(1단계와 같다): ICE는 투명 컵·얼음·빨대, HOT은 뚜껑·슬리브 종이컵과 김, 상온은 얼음 없는 투명 컵.
- 색은 분류다: 커피 #a87652, 티 #c99245, 스무디·주스 #c4664f, 에이드 #d9a03a, 기타 #6e4a38. 실제 음료 색이 아니라는 점을 상세 화면 안내와 대체 텍스트에 밝힌다.
- 대체 텍스트 예: "매실 모과차, 따뜻한 음료, 591ml, 티 분류 공통 일러스트". 상세 화면의 그림 안내는 "제품 사진 대신 컵 높이로 용량, 색으로 분류를 나타낸 공통 일러스트"로 바꾼다.
- 실제 제품 사진이 있으면 지금처럼 사진이 우선이다. 특정 음료가 아닌 취향 노트 장식 컵은 새 그림체의 기본 높이 아이스 컵을 실선으로 그린다(용량 미제공 점선을 쓰지 않는다). 구현 중 결정(2026-11-13): 기존 그림체는 크기가 바뀌는 컵과 함께 쓸 수 없어 장식 컵도 새 그림체로 통일했다.
- 기존 컵 그림 안의 "한컵 / A LITTLE DISCOVERY" 문양은 크기가 바뀌는 컵에서 찌그러지므로 뺀다.

## 2. 압축한 음료 카드
- 그림 영역을 줄인다(390px 기준 카드 높이 약 280px 목표, 지금 약 380px).
- 브랜드 줄에 온도·사이즈·용량을 합친다: "이디야 · ICE · L · 520ml". 그림 위 온도 배지는 없앤다(그림 모양과 브랜드 줄이 같은 정보를 준다). 구현 중 결정(2026-11-13): 사이즈가 "기본"이면 브랜드의 단일 사이즈라는 뜻뿐이라 생략한다("메가MGC커피 · ICE · 591ml"). 그래야 390px에서 한 줄에 들어간다.
- 영양 숫자는 1단계 기준(14px 고정폭, 360px 미만 13px)을 유지한다.
- 평가와 비교 버튼을 한 줄로 둔다. 가격이 확인된 음료는 같은 줄에 "4,500원"처럼 보이고, 미제공이면 카드에서는 생략한다(상세 화면은 지금처럼 "가격 미제공" 표시). 0원으로 보이는 일은 없다.
- 좋아요·비교 버튼의 동작과 접근 가능한 이름("비교 담기" 등)은 유지한다.

## 3. 한 줄 검색 필터
- 검색창 안내문을 "음료명이나 브랜드"로 줄여 잘리지 않게 한다.
- 분류는 칩 한 줄(가로 스크롤)로만 고른다. 폼 안의 분류 선택 상자는 없애고, 칩이 고른 분류는 폼 제출 때 숨은 값으로 유지한다.
- 브랜드·온도는 지금의 선택 상자를 칩 모양으로 바꿔 한 줄에 둔다(이름·값 유지).
- 영양 상한(칼로리·당류·카페인)은 "영양 조건" 펼침 패널로 옮긴다. 상한이 하나라도 설정되면 버튼에 개수("영양 조건 1")를 표시하고 패널을 펼친 상태로 보여준다. 패널 안 입력 안내는 "전체" 대신 "제한 없음"으로 바꾼다.
- 패널에 빠른 선택 "당류 10g 이하", "카페인 10mg 이하"를 둔다. 지금의 상한 값을 채운 검색 링크일 뿐이며, 현재 기준(한 잔/100ml)을 따른다. 100ml 기준이면 "100ml당"을 붙인다.
- "조건 초기화"는 칩 줄 끝이 아니라 결과 수 옆에 둔다(320px에서도 보이게).
- 구현 중 결정(2026-11-13): "필터 적용" 버튼은 패널 밖 필터 줄에 둔다. 패널 안에 두면 브랜드·온도만 바꿀 때도 패널을 열어야 하기 때문이다. 패널을 펼치면 패널이 필터 줄 아래 한 줄 전체를 차지한다.
- 제안 목업의 아래에서 올라오는 시트 대신, 자바스크립트 없이 동작하는 접히는 패널(`details`)로 구현한다. 서버 렌더링·URL 상태가 그대로 유지된다.

## 유지
검색·필터·정렬·기준·페이지 이동은 지금처럼 URL에 남는다. 기준을 바꾸면 영양 상한을 비우는 규칙, 정보 없는 음료를 상한 필터에서 제외하는 규칙, 최대 3개 비교, 좋아요 동작, 접근 가능한 이름(“필터 적용”, “정렬 적용”, “비교 담기”, “조건 초기화”, “당류 상한” 등)을 유지한다. API·DB 변경 없음.

## 제외
홈 신메뉴 묶음, 비교표 3열 맞춤, 상세 행동 버튼 정리는 3단계다.

## 검증
- 컵: 카드·상세·비교 그림의 대체 텍스트에 온도·용량·분류가 있고, 비교 화면에서 520ml 컵과 670ml 컵의 그려진 높이 비율이 용량 비율과 맞는다.
- 카드: 390px에서 카드 높이, 브랜드 줄 정보, 가격 미제공 생략, 비교·좋아요 동작.
- 필터: 칩·선택·패널·빠른 선택이 기존 URL 매개변수를 만들고 다른 조건을 보존한다. 1단계 가독성 검사와 기존 브라우저 테스트가 계속 통과한다. 기존 테스트는 영양 입력 전에 패널을 여는 한 단계만 추가한다.
