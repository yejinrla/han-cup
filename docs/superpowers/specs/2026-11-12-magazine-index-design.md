# 한컵 매거진 글 모아보기

## 목적
홈 배너에서 지나친 글을 다시 찾고, 운영자가 작성한 추천 글을 한곳에서 읽는다.

## 선택한 방식과 대안
- 선택: 홈 배너 근처의 ‘매거진 전체 보기’에서 카드형 목록으로 이동한다. 현재 글 3개에 적합하며 기존 하단 탐색을 유지한다.
- 대안: 하단 매거진 탭은 상시 접근이 쉽지만 현재 콘텐츠 규모에서는 비중이 크다. 글이 쌓이면 재검토한다.
- 대안: 홈에 모든 글을 펼치면 이동은 줄지만 음료 탐색 영역이 길어진다.

## 화면과 동작
- 홈 배너 위에 ‘한컵 매거진’ 제목과 ‘전체 보기’ 링크를 배치한다. 링크의 접근성 이름은 ‘매거진 전체 보기’로 한다.
- 목록 경로는 기존 상세 경로와 연결되는 `/notes`로 제안한다.
- 목록 제목은 ‘한컵 매거진’, 소개는 ‘취향에 맞는 한 잔을 찾는 이야기’로 한다.
- 모바일과 PC의 기존 480px 앱 프레임 안에서 세로 한 열의 카드를 표시한다.
- 카드에는 기존 컵 일러스트 썸네일, 글 제목, 짧은 소개를 표시한다. 카드 전체를 누르면 기존 글 상세로 이동한다.
- 현재 글 3개를 기존 콘텐츠 배열 순서로 보여준다. 날짜가 없으므로 최신순이라는 표시는 하지 않는다.
- 상세 화면에 ‘매거진 전체 보기’ 링크를 추가한다. 기존 ‘홈으로’ 링크도 유지한다.
- 목록에서도 하단 홈 탭을 활성화한다. 사이트맵에 목록 경로를 추가한다.

## 범위와 제약
기존 글 데이터와 일러스트를 재사용한다. 로그인 없이 읽을 수 있다. 관리자 작성 화면, 카테고리 필터, 검색, 페이지네이션, 별도 하단 탭은 이번 범위에 포함하지 않는다. 일러스트 크기와 카드 여백은 기존 배너 톤에 맞춰 구현자가 조정한다.

## 검증
홈에서 목록으로 이동, 카드에서 글 상세로 이동, 상세에서 목록으로 이동, 세 글 표시, 홈 탭 활성화, 320px 및 PC 화면에서 가로 넘침 없음을 확인한다. 린트·타입 검사·빌드를 수행한다.
