# 검색 결과를 한 줄 목록으로 (시안 C)

작성일: 2026-11-17 (한국 시간). 상태: 사용자 승인 완료(2026-11-17). 찜 버튼 유지, 한 줄에서 "평가 없음" 숨김, 테스트 경계 세 개 승인. 2026-11-17 결과 화면 시안 비교(지금/A/B/C)에서 사용자가 C "촘촘한 목록 + 비교"를 골랐다.

## 배경
검색 결과 화면(`/search?all=1`, 검색어·필터가 있는 `/search`)에서 위에 "← 검색 홈" 줄이 생긴 뒤, 390×844 첫 화면에 온전히 보이는 음료가 0개다(첫 카드 534px, 하단 탭 768px). 사용 기록이 없어 가장 많이 하는 동작은 측정되지 않았다. 사용자는 한 화면에 많은 음료를 나란히 보고 비교로 넘어가는 방향을 골랐다.

## 기존 결정과의 관계
2026-11-12 설계서의 시각 방향 "C(이미지 카드와 핵심 수치의 균형)"는 홈 신메뉴·인기 음료·좋아요·아티클 추천의 카드에 그대로 유지한다. 이 변경은 **검색 결과 목록에만** 한 줄 형태를 쓰는 예외이며, 사용자가 2026-11-17에 직접 골랐다.

## 한 줄의 구성
- 왼쪽: 작은 컵 그림(지금 카드와 같은 온도·용량 반영 그림, 상세로 가는 링크).
- 가운데: 메타 한 줄(브랜드 · 온도 · 사이즈 · 용량, 지금 규칙 그대로), 음료명(상세 링크, 최대 두 줄), 영양 세 값 한 줄 "칼로리 110kcal 당류 8g 카페인 40mg". 미제공은 지금처럼 "미제공"으로 쓴다. 100ml 기준 전환도 지금처럼 동작한다.
- 오른쪽: 비교 담기 버튼과 좋아요(찜) 버튼. 둘 다 지금과 같은 컴포넌트·접근 가능한 이름을 쓴다.
- 평점: 참여자가 있을 때만 "★ 4.2 (3)"으로 보인다. "평가 없음"은 한 줄에서 자리를 차지하지 않는다(상세 화면이 계속 알려준다).
- 가격: 확인된 경우에만 보인다(지금 규칙).

## 유지
필터·정렬·검색어·URL·페이지 크기(24개)·비교 트레이(하단 여백 확보 포함)·좋아요 동작. 색 토큰과 글꼴, 가독성 기준(글자 11px 이상, 대비 AA), 320px에서 가로 넘침 없음. 결과 화면 로딩 뼈대도 한 줄 모양으로 맞춘다. DB 변경 없음.
