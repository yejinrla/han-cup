# 홈 신메뉴 묶음, 세 잔 비교, 상세 행동 정리 (UI 개선 3단계)

작성일: 2026-11-14 (한국 시간). 상태: 사용자 승인 완료(2026-11-14, "3단계 진행해줘"). UI 개선안(https://claude.ai/artifact/AQs87mnHFYTzQtNqk53MHv)의 제안 4·5·6이다. 1·2단계 위에서 진행한다.

## 1. 홈 신메뉴를 한 묶음으로
- 출시일과 출처가 같은 신메뉴는 한 묶음으로 보여준다. 묶음마다 출처 줄을 한 번만 쓴다: "메가MGC커피 · 2026-10-29 출시 · 공식 출시 정보". 날짜나 출처가 다르면 묶음을 나눈다.
- 묶음 안의 음료는 2단계 압축 카드를 가로로 넘겨보는 한 줄로 놓는다. 세 번째 카드가 혼자 한 줄을 차지하지 않고, 신메뉴가 늘어도 홈이 길어지지 않는다. 페이지 자체는 가로로 넘치지 않는다.
- 카드의 좋아요·비교, 검수된 신메뉴만 노출하는 규칙, 빈 상태 안내는 그대로다.

## 2. 세 잔을 한눈에 비교
- 390px에서 세 열이 모두 보이도록 항목명 열을 좁히고 컵 그림을 줄인다. 더 좁은 화면에서만 표 영역 안에서 가로로 스크롤한다.
- 가격·칼로리·당류·카페인에서 가장 낮은 값에 "가장 낮음"을 글자로 표시한다(색만으로 구분하지 않는다).
  - 비교하는 모든 음료의 값이 확인된 항목에서만 표시한다. 미제공 값이 섞이면 표시하지 않는다(없는 값을 0이나 높은 값처럼 다루지 않는다).
  - 가장 낮은 값이 여럿이면 표시하지 않는다.
  - 영양 항목은 현재 기준(한 잔/100ml)의 값으로 판단한다. 가격은 100ml 기준에서도 화면에 보이는 한 잔 가격으로 판단한다(비교 화면이 "가격은 한 잔 가격을 유지"한다고 안내하며, 표시된 값과 다른 값으로 판단하지 않기 위해서다). 결정: 2026-11-14 독립 리뷰 후.
- 컵 용량과 공개 평점에는 표시하지 않는다(낮을수록 좋은 값이 아니다).

## 3. 상세 화면 행동 정리
- "한 잔 기록하기"를 아래 공개 후기 영역에서 음료 이름·변형 선택 아래로 옮겨 주요 행동으로 둔다(같은 링크를 두 번 두지 않는다). 로그인하지 않았으면 지금처럼 로그인 안내로 이동한다.
- 비교·찜·주변 매장은 같은 높이(44px 이상)의 버튼 세 개로 한 줄에 둔다. 찜 버튼은 상세 화면에서 "찜하기"/"찜 해제" 글자를 함께 보인다(카드의 찜 버튼은 아이콘만 유지). 접근 가능한 이름("비교 담기", "음료 찜하기", "음료 찜 해제")은 유지한다.
- 공개 후기 영역은 제목("이 한 잔, 어땠나요?")과 후기 목록을 유지한다.
- 구현 중 결정(2026-11-14): 360px 미만에서는 "주변 매장 찾기"가 단어 단위로 두 줄이 되고 아이콘을 숨긴다. 비교가 가득 찼다는 안내 같은 상태 문구는 세 버튼 아래 한 줄 전체를 쓴다.

## 유지
기능, 데이터, URL, 비교 최대 3개, 평점·개인정보 규칙, 접근 가능한 이름, 480px 앱 화면. API·DB 변경 없음.

## 검증
- 홈: 같은 출시 묶음의 출처 줄이 한 번만 보이고, 카드 3장이 가로 한 줄에 있으며 페이지가 넘치지 않는다.
- 비교: 390px에서 세 열이 표 영역 안에 다 들어오고, "가장 낮음"이 규칙대로 표시·생략된다.
- 상세: "한 잔 기록하기"가 영양정보보다 위에 하나만 있고, 세 보조 버튼의 높이가 같고 44px 이상이다. 기존 브라우저·가독성 테스트가 계속 통과한다.
