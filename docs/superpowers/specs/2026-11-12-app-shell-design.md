# 한컵 앱 중심 웹 UI

사용자가 승인한 구성: 모바일 웹과 향후 앱을 중심으로, PC에서도 최대 약 480px의 앱 화면을 가운데 배치한다. 양옆은 은은한 배경이며 모바일에서는 전체 화면을 쓴다. 기존 초록·크림색을 유지한다.

모든 화면에 음료 도감·주변 매장·좋아요·나의 한컵 네 개의 하단 탭을 고정한다. 현재 경로의 탭은 초록색과 aria-current로 구분한다. 음료 상세와 비교는 도감에 속하며 개인 설정은 나의 한컵에 속한다. 상단은 로고·현재 화면 맥락·로그인으로 간결하게 정리한다.

동일한 컴팩트 레이아웃을 모든 브라우저 폭에서 사용한다. 기존 넓은 화면용 레이아웃 대신 2열 음료 카드, 세로형 상세·매장 화면과 후기 달력을 유지한다. 비교표는 그 영역에서만 가로 스크롤한다. 본문·비교 선택 바·하단 탭이 겹치지 않도록 높이와 안전 영역을 반영한다. 키보드 포커스와 본문 바로가기, 브라우저 확대를 유지한다.

대안은 PC 사이드바였으나 사용자는 PC에서도 모바일 앱과 같은 구성을 원해 중앙 앱 프레임을 선택했다. 데이터·인증·검색·후기 기능과 기존 URL은 유지한다. 네이티브 앱 제작은 후속 작업이다.
