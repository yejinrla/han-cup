# 음료 기록의 커스텀 옵션

작성일: 2026-11-14 (한국 시간). 상태: 초안 — 사용자 승인 대기. 한컵 설계서(2026-11-12-hancup-design.md) "추후 확장"의 "커스텀 옵션 기록"이다.

## 목적
같은 음료라도 샷 추가, 시럽 조절, 얼음 양처럼 주문 방식에 따라 맛이 달라진다. 기록할 때 어떤 옵션으로 마셨는지 함께 남겨, 나중에 "이번엔 시럽을 줄여 볼까" 같은 판단에 쓰게 한다.

## 범위

### 고를 수 있는 옵션 (정해진 목록)
자유 입력 대신 정해진 옵션만 고른다. 브랜드마다 이름이 달라도 뜻이 통하는 공통 표현을 쓰고, 세부 내용(예: "바닐라 시럽 1펌프")은 기존 메모 칸에 적는다.

| 분류 | 옵션 |
|---|---|
| 샷 | 샷 추가 · 연하게 |
| 단맛 | 시럽 추가 · 시럽 적게 · 시럽 빼기 |
| 우유 | 우유 변경 |
| 카페인 | 디카페인으로 변경 |
| 얼음 | 얼음 적게 · 얼음 많이 |
| 토핑 | 휘핑 추가 · 휘핑 빼기 |

- 한 기록에 최대 5개까지 고른다.
- 서로 반대인 옵션은 함께 고를 수 없다: 샷 추가/연하게, 시럽 추가/적게/빼기, 얼음 적게/많이, 휘핑 추가/빼기.
- 옵션은 선택 사항이다. 고르지 않은 기록은 지금과 똑같다.

### 정직성 원칙
- 옵션을 골라도 영양정보를 다시 계산하지 않는다. 기록 폼과 옵션이 보이는 곳에 "커스텀 옵션은 영양정보에 반영되지 않아요"라고 짧게 안내한다. 설계서의 "초기에는 커스텀 영양정보 계산을 하지 않는다" 원칙을 유지한다.
- 평균 평점 집계 규칙(사용자별 최신 공개 별점 하나)과 인기 집계는 바꾸지 않는다. 옵션별로 평점을 나누지 않는다.

### 공개 범위
- 옵션은 기록의 공개 여부를 그대로 따른다. 나만 보기 기록의 옵션은 본인만 보고, 공개 기록의 옵션은 공개 후기에 함께 보인다.
- 인기 집계에는 옵션이 들어가지 않는다(지금처럼 음료별 기록자 수만).

### 화면
- **기록 폼**(상세 → 한 잔 기록하기, 나의 한컵 인라인 편집): 별점·날짜·공개 범위 아래에 분류별 칩(체크 버튼)으로 고른다. 반대 옵션을 고르면 앞서 고른 반대 옵션이 해제된다. 5개를 넘기면 더 고를 수 없다고 안내한다. 자바스크립트 없이도 제출 시 서버가 같은 규칙으로 검증한다.
- **나의 한컵 기록 목록**과 **공개 후기 목록**: 별점·날짜 아래에 고른 옵션을 작은 칩으로 보인다.
- 1단계 가독성 기준(11px 이상, 대비 AA)과 접근 가능한 이름 규칙을 따른다. 칩은 `aria-pressed` 대신 실제 체크박스로 만든다.

## 데이터
- `reviews`에 `options text[] not null default '{}'` 열을 추가한다. DB 제약으로 허용 목록에 있는 값만, 최대 5개, 중복 없이 저장한다. 반대 옵션 조합 금지는 앱(zod)과 DB 제약 둘 다에서 막는다.
- 공개 후기 함수 `public_reviews`가 공개 기록의 옵션을 함께 돌려준다. 비공개 기록은 지금처럼 반환하지 않는다.
- 새 마이그레이션 `009_review_options.sql`: 추가만 하고 기존 데이터를 바꾸지 않으며 다시 실행해도 안전하게 쓴다. 기존 RLS 규칙은 바꾸지 않는다.

## 배포 순서 (중요)
새 코드는 `options` 열을 읽고 쓴다. 운영 DB에 009가 적용되기 전에 코드가 배포되면 기록 저장이 실패할 수 있다. 그래서 다음 순서를 지킨다.
1. 사용자가 운영 SQL Editor에서 `009_review_options.sql` 실행
2. 확인 쿼리로 적용 확인(`production-db.md`에 추가)
3. 그다음 PR을 합쳐 배포

또는 코드가 열이 없을 때 옵션 없이 저장하도록 대비할 수도 있으나, 실패를 숨길 수 있어 위 순서를 기본으로 한다.

## 제외
옵션별 영양 계산, 옵션별 평점·인기, 옵션으로 검색·필터, 브랜드별 실제 옵션명·가격, 자유 입력 옵션.

## 검증 (구현 시 테스트 경계는 별도로 확인받는다)
- 검증 규칙: 허용 옵션만, 최대 5개, 반대 조합 거부, 빈 목록 허용.
- DB: 제약이 잘못된 값을 막고, 공개 함수가 공개 기록의 옵션만 돌려준다(비공개 원문·옵션 비노출).
- 화면: 기록 폼에서 고르고 저장한 옵션이 나의 한컵과 공개 후기에 보이고, 영양정보 미반영 안내가 있다. 가독성 검사 통과.
