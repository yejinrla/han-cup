# 나의 한컵 달력

## 목적과 범위
마신 기록을 날짜별로 돌아볼 수 있게 기존 최신순 목록을 월간 달력과 선택일 후기 목록으로 바꾼다. 기본 선택일은 한국 시간의 오늘이며, 날짜는 작성일이 아닌 consumed_on(마신 날짜)을 사용한다.

## 접근 방식
사용자가 선택한 방식은 월간 달력 아래에 선택일 후기를 보여주는 구성이다. 팝업 방식보다 모바일에서 여러 후기를 읽고 수정하기 쉽다. 기존 Next.js 페이지와 Supabase 후기 데이터를 사용한다. 별도의 달력 라이브러리나 DB 변경은 필요하지 않다.

## 화면과 동작
- 위쪽에 표시 월, 이전/다음 달, 오늘로 돌아가기 버튼을 배치한다.
- 일요일부터 시작하는 7열 달력. 오늘 표시와 선택일 강조를 구분한다.
- 본인의 공개/비공개 후기가 있는 날짜에는 점을 표시한다.
- 날짜를 선택하면 아래에 해당 날짜의 후기만 표시한다. 여러 후기는 작성 시각 최신순이다.
- 기록이 없는 날은 해당 날짜에 기록이 없다는 안내와 음료 둘러보기 링크를 제공한다.
- 기존 음료별 후기 작성, 수정, 삭제, 공개 범위 변경을 유지한다.
- 찜한 음료와 계정 설정 탭을 유지한다.

## 구현자가 정할 기본값
- 다른 달로 이동하면 기존 선택일의 일자를 유지하되, 해당 월 말일을 넘으면 말일을 선택한다.
- 선택 날짜를 URL에 보관한다. 날짜가 없거나 잘못됐으면 한국 시간 오늘을 선택한다.
- 수정 링크에는 선택 날짜를 유지한다. 마신 날짜를 변경하면 달력의 점과 해당일 목록이 최신 데이터로 갱신된다.
- 월별 기록 표시는 기존 목록의 20개 제한에 잘리지 않게 날짜 정보만 별도로 조회한다. 선택일 후기가 많으면 기존과 같이 20개 단위로 추가 페이지를 제공한다.
- 날짜 링크에 전체 날짜, 오늘, 후기 존재 여부를 접근 가능한 이름으로 제공한다.

## 제외와 검증
사진 업로드, 통계, 공유 달력, DB 스키마 변경은 범위 밖이다. 한국 시간 날짜 경계, 윤년/월 이동, 기본 오늘 선택, 날짜별 후기 필터와 기존 수정/삭제 동작을 검증한다. 사용자별 권한 필터는 유지한다.
